## ¿Qué es SalonHairAgent?

SalonHairAgent es un agente conversacional desarrollado por Xyon Platforms para la gestión automática de reservas en salones de peluquería y centros de estética. Permite a los clientes reservar citas mediante conversación natural y gestiona la agenda del salón de forma automática.

## ✨ Funcionalidades

- **Reservas automáticas** mediante agente conversacional
- **Gestión de agenda** del salón en tiempo real
- **Notificaciones** de confirmación y recordatorio
- **Panel de administración** para gestionar citas y clientes
- **Despliegue self-hosted** vía Docker

## 🛠️ Stack técnico

| Capa | Tecnología |
|------|----------|
| Backend | Node.js + TypeScript |
| Agente | IA conversacional |
| Despliegue | Docker |

## 🚀 Instalación

```bash
git clone https://github.com/mkandreum/salonhairagent.git
cd salonhairagent
cp .env.example .env
docker-compose up -d
```

### Desarrollo local

```bash
npm install
npm run dev
```
